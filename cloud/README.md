# 微信云开发接入指引（社团小程序）

本项目已内置「本地 mock」与「微信云开发」双模式。默认 `USE_CLOUD = false`（本地模式，无需后端即可过审预览）。
当你希望**所有社员看到同一份招新数据、公告、活动**，而不是各看各的本地缓存时，请按以下步骤开启云开发。

---

## 一、开通云开发环境
1. 用**你自己的**微信账号打开「微信开发者工具」，导入本项目。
2. 顶部工具栏点击 **「云开发」** → **开通** → 新建一个环境（如 `club-prod`），复制环境 ID。
3. 把环境 ID 填进 `utils/cloud-config.js` 的 `env` 字段：
   ```js
   module.exports = { env: '你的环境ID', useDefaultEnv: false }
   ```

## 二、创建数据库集合
在「云开发控制台 → 数据库」中新建以下集合（名称必须完全一致）：
```
clubInfo  announcements  activities  trainings
honors    gallery        banners     sects
```
> 每个集合会以 `_id = 'main'` 的单个文档存储数据，无需手动建字段。

## 三、部署云函数
在左侧资源管理器，**分别右键** `cloud/club-data` 与 `cloud/init-db` →
「**上传并部署：云端安装依赖**」。

## 四、一键灌入初始数据
最省事的方式：把 `USE_CLOUD` 改为 `true` 后，用管理员账号登录小程序，
进入**后台管理 → 点击「☁️ 同步数据到云端」**，即可把当前本地数据全量写入云数据库。
（也可在云函数 `init-db` 的「测试」中传入完整数据对象完成初始化。）

## 五、切换模式
打开 `utils/data-manager.js`，把顶部：
```js
const USE_CLOUD = false
```
改为：
```js
const USE_CLOUD = true
```
此后 `app.js` 启动时会自动 `wx.cloud.init` 并从云端拉取最新数据回填本地缓存，
**页面无需任何改动**即可展示云端内容。

---

## 说明
- 云开发按量计费，个人小程序有免费额度，社团量级完全够用。
- 若环境 ID 填错或未部署云函数，应用会自动回退到本地缓存，不会白屏。
- 当前 `USE_CLOUD` 默认仍为 `false`，保证你现在上传预览即可正常运行。
