# 软件与算法社团 · 小程序

## 关于社团

软件与算法社团致力于为编程爱好者提供学习、交流、实践的平台。涵盖算法竞赛（ACM/蓝桥杯）、软件开发（Web/App/小程序）、人工智能、数据结构等方向。

## 模块说明

| 模块 | 路径 | 说明 |
|------|------|------|
| 首页 | `pages/index/` | 社团简介、公告、功能入口 |
| 招新 | `pages/recruitment/` | Tab（简介/日程/荣誉）、详情、报名 |
| 风采 | `pages/gallery/` | 活动照片瀑布流 |

| 后台管理 | `pages/admin/` | 系统、用户、内容、报名、名单管理（已分包） |

## 快速开始

1. 打开微信开发者工具
2. 选择项目目录 `C:\Users\Administrator\Desktop\社团管理小程序`
